# Lightbox Gallery

A lightweight image card gallery with a custom lightbox/modal viewer, built with vanilla JS (jQuery) and CSS — no build tools, no frameworks.

## Features

- Responsive card grid gallery
- Lightbox modal with next/prev navigation
- Pagination bullets with an auto-scrolling overflow window
- Disabled arrow states on the first/last slide
- Mobile-friendly lightbox (nav arrows stay tappable over full-bleed images)

## Usage

Serve the project from its root with any static file server (asset paths are absolute, e.g. `/assets/...`), then open `index.html`:

```bash
python -m http.server 8080
```
